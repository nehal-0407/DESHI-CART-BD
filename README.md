# DESHI-CART-BD — GitHub Pages

1. Upload `index.html` to the root of your GitHub repository.
2. In GitHub: Settings → Pages.
3. Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/(root)**
6. Save.
